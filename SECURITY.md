# Security policy

AgentFirewall is a testnet/reference implementation and has not been audited for production custody. Do not use mainnet, production treasury or custody keys with this repository.

## Reporting

Report security issues through GitHub private vulnerability reporting. Public issues must not contain private keys, seed phrases, RPC credentials, or exploitable production secrets.

## Scope

The documented trust assumptions and known limitations are in `THREAT_MODEL.md`. A successful demo or testnet run is not a claim of production safety.
